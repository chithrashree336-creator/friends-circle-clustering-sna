# Friends Circle Clustering in Online Social Networks Using Social Network Analysis

## 📌 Project Overview

This project focuses on identifying meaningful friend circles in online social networks using **Social Network Analysis (SNA)**.

Users are represented as **nodes**, while interactions or relationships between users are represented as **edges**. The project applies network analysis, community detection, and clustering techniques to understand how users form groups within a social network.

## 🎯 Objective

The main objective is to:

* Identify meaningful communities or friend circles in a social network.
* Analyze relationships and interactions between users.
* Measure the importance of users within the network.
* Detect community structures using clustering techniques.
* Visualize and interpret the identified friend circles.

## 🔄 Project Workflow

**Data Collection → Data Preprocessing → Graph Construction → Network Analysis → Community Detection → Visualization → Result Analysis**

### 1. Data Collection

Social network interaction data is collected to represent users and their relationships.

### 2. Data Preprocessing

The collected data is prepared and organized for network analysis.

### 3. Graph Construction

The social network is represented as a graph consisting of nodes and edges.

### 4. Network Analysis

Network properties are analyzed using measures such as:

* Degree Centrality
* Betweenness Centrality
* Modularity

### 5. Community Detection

Community detection techniques are used to identify groups of closely connected users.

The project explores **Louvain community detection** and **K-Means clustering**.

### 6. Visualization

The identified communities and network relationships are visualized to make the structure of the social network easier to understand.

### 7. Result Analysis

The detected communities and network metrics are analyzed to understand friend-circle patterns and important users within the network.

## 📊 Key Metrics

### Degree Centrality

Measures the number of direct connections associated with a user.

### Betweenness Centrality

Helps identify users who act as important bridges between different parts of the network.

### Modularity

Measures how strongly a network can be divided into distinct communities.
